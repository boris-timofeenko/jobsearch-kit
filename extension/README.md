# Job Autofill — расширение для Firefox (и Safari)

Кнопка на панели браузера или `Alt+Shift+J` (на Mac `⌥⇧J`) заполняет пустые поля формы отклика данными из CV:
имя и фамилию, почту, телефон (с кодом страны или без, если рядом есть отдельный выбор кода), город, страну и адрес,
LinkedIn, GitHub, сайт, текущую компанию и должность, блоки опыта и образования (Workday, Workable), стаж, уровень
английского, гражданство, зарплатные ожидания, срок уведомления. Прикрепляет PDF CV в поле Resume/CV (не в Cover
letter). Отвечает на типовые вопросы да/нет: нужна ли виза (да), есть ли право работать в стране (нет), готовность к
переезду и гибриду (да), 18+ (да), нидерландский/немецкий (нет), опыт с инструментом (да, только если он есть в
CV). В EEO-вопросах (gender, ethnicity, veteran, disability, pronouns) выбирает «prefer not to say», если такой
вариант есть.

Чего не делает: не отправляет форму (клики по кнопкам внутри формы страхуются от отправки), не ставит галочки
согласий, не трогает уже заполненные поля, не пишет cover letter и «почему мы». Повторный клик безопасен: на
многошаговых формах (Workday, LinkedIn Easy Apply) жми на каждом шаге.

Подсветка: 🟩 заполнено, 🟧 заполнено, но проверь (зарплата, да/нет, стаж, гражданство, EEO), 🟦 не заполнено,
заполни сам. Подсветка пропадает, когда ставишь курсор в поле. Итог в углу страницы, на значке — число полей.

Что проверено: логика заполнения — в Chromium (Playwright) на живых формах Greenhouse (новые React-формы), Lever
и Ashby тестовым профилем без отправки и без файла, плюс на копиях форм в `test/fixtures` (старый Greenhouse, Lever,
Ashby, Workday). В Firefox 156 проверены линт и установка; клик по кнопке в самом Firefox, iframe и shadow DOM
(скрипт в них заходит) — пока без проверки. Workday, SmartRecruiters и LinkedIn Easy Apply вживую не открывались.

## Установка в Firefox

1. Собрать профиль и PDF (из корня проекта):
   ```bash
   .venv/bin/python -m jobsearch autofill
   ```
   Пишет `extension/profile.json` и `extension/cv.pdf` (оба в `.gitignore`). `--pdf data/cv/<файл>.pdf` — положить
   вместо базового CV готовый PDF, например собранный ботом под вакансию.
2. Временная установка (до перезапуска Firefox): `about:debugging#/runtime/this-firefox` → «Загрузить временное
   дополнение…» → выбрать `extension/manifest.json`. После правок кода там же кнопка «Перезагрузить».
3. При первом клике Firefox спросит доступ ко всем сайтам: он нужен, чтобы заполнять формы во встроенных iframe
   (Greenhouse на сайте компании). Без него работает только сама страница.

### Постоянная установка (подписанный .xpi)

Обычный Firefox ставит насовсем только подписанные Mozilla дополнения. Подпись бесплатная: пакет загружается на
addons.mozilla.org как unlisted (в каталоге не виден), проверяется автоматически за минуты, возвращается `.xpi`.
В пакет идут только код и иконки; `profile.json`, `cv.pdf`, tex и yaml туда не попадают (`web-ext-config.mjs`,
`sign.sh` проверяет состав пакета перед загрузкой).

1. Войти на addons.mozilla.org (аккаунт Mozilla), Developer Hub → Tools → Manage API Keys → Generate new
   credentials. В `.env` проекта дописать:
   ```
   AMO_JWT_ISSUER=user:…
   AMO_JWT_SECRET=…
   ```
2. Подписать:
   ```bash
   extension/sign.sh
   ```
   Готовый файл — `extension/web-ext-artifacts/<хэш>-<версия>.xpi`. Одну версию AMO подписывает один раз,
   поэтому при повторной подписи скрипт сам поднимает последнюю цифру версии в `manifest.json`.
3. Если стоит временная копия, удалить её в `about:debugging`. Затем `about:addons` → ⚙ → «Установить дополнение из
   файла…» → `.xpi`.
4. Настройки расширения: «Импортировать profile.json» (`extension/profile.json`) и «Выбрать PDF»
   (`extension/cv.pdf`). Они хранятся в локальном хранилище Firefox и переживают перезапуски. После правок CV —
   `jobsearch autofill` и повторный импорт; после правок кода — снова `sign.sh` и установка нового `.xpi`.

## Safari (macOS)

Нужен полный Xcode из App Store (сейчас на этом Mac только Command Line Tools). Дальше:
```bash
xcrun safari-web-extension-converter extension --macos-only --app-name "Job Autofill" --project-location ~/Documents/Projects
```
В открывшемся Xcode-проекте: Signing → «Sign to Run Locally» (или бесплатный Apple ID), Run. В Safari: Настройки →
Дополнения → «Показывать функции для веб-разработчиков», затем Настройки → Разработчик (в старых версиях меню
Разработка) → «Разрешить неподписанные расширения» (сбрасывается при перезапуске Safari) и включить Job Autofill в
Настройки → Расширения. Профиль и PDF — через настройки расширения. Под Safari не проверялось.

## Настройки расширения

`about:addons` → Job Autofill → Настройки: импорт `profile.json`, выбор другого PDF (например, CV под вакансию из
Telegram-бота), выключатель «прикреплять CV». Импортированное важнее встроенного `profile.json`/`cv.pdf`.

## Откуда данные

`jobsearch/autofill.py` разбирает `my/cv.tex`: имя, телефон, почта, ссылки (`\href`), `\cvheadline`,
`\cvlocation`, summary, строку языков, `\skillrow`, `\role` + `\ctx` + буллеты, строки образования. Стаж считает
само расширение по датам опыта на момент клика (всего, QA, лид). То, чего в CV нет, — в разделе `autofill:` файла
`cv_bank.yaml`: адрес, индекс, гражданство, срок уведомления, дата выхода, источник («LinkedIn»), зарплата
(месяц / год / текст), пол, стаж по инструментам. Пустое значение — поле остаётся синим.

## Разработка

Логика — `fill.js` (внедряется во все фреймы по клику, без постоянных content scripts): сбор полей, подпись поля
(`<label>`, `aria-labelledby`, текст вопроса вокруг поля, атрибуты name/id/placeholder/data-automation-id), правило
по подписи (сначала видимая подпись, атрибуты — только если подпись ни к чему не подошла), запись значения так,
чтобы увидели React/Vue (нативный сеттер + события), затем по одному выпадающие списки: react-select открывается
mousedown/touchend на контроле, Workday — кликом по кнопке, подсказки локации — после ввода текста.
Правила — массив `RULES`, порядок важен.

```bash
cd extension
npm install && npx playwright install chromium   # один раз
npm test                                          # фикстуры форм в test/fixtures
npm run lint                                      # web-ext lint (Firefox)
npm start                                         # временный профиль Firefox с расширением
```
